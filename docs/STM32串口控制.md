# STM32 串口控制（仅上位机）

本项目的实车边界是：**ROS 上位机使用下位机工程已有的 USART1 协议；不修改、不烧录底层固件。** 下位机工程为 `/home/ch/02_落地工程_算法库`。

## 现有协议

USART1 为 115200 8N1。下位机上行是 VOFA+ FireWater：

```text
channels:ch0,ch1,...,ch15\n
```

16 个十进制数，逗号分隔，换行结束。桥接只把完整的 16 通道、全为有限数值的帧当作有效反馈。来自原工程的通道含义：

| 通道 | 含义 | 单位 |
|---|---|---|
| 0/1 | 左轮实际/目标速度 | 转/秒 |
| 2/3 | 右轮实际/目标速度 | 转/秒 |
| 4/5 | 左右轮位置 | 圈 |
| 6/7 | 左右轮位置误差 | 圈 |
| 8/9/10 | 实际/目标/误差航向 | 度 |
| 11 | 航向差速修正 | 脉冲/周期 |
| 12/13/14 | 里程计 X/Y/距原点距离（`DBG_ODOMETRY=1`） | mm |
| 15 | 行驶调用、路线状态、陀螺仪标志和底盘状态 | 编码值 |

底盘状态是 CH15 的个位：0 空闲、1 行驶、2 稳身、3 精修、4 完成、5 原地掉头。桥接用个位 0/4 判断当前 `$D` 已结束。

下行只用 `$D`：

```text
$D<距离mm>,<最大速度转/秒>,<前轮角度>

```

前轮角正为左、负为右；速度为 `v / (π × 0.123)`。桥接把 ROS 的线速度和角速度换算为：

```text
前轮角 = atan(0.325 × 角速度 / 线速度)
```

并以 20 mm 为默认短段，避免单次动作过长。例如 `v=0.06 m/s, ω=0.02 rad/s` 会生成：

```text
$D20.0,0.155,6.18
```

实车畅通时的目标速度为 0.20 m/s，谨慎通行为 0.12 m/s。每段仍为 20 mm，实际平均车速还取决于底盘起步、减速和段间等待。在实测新速度的停车距离之前，上位机按速度比的平方放大旧制动距离预算。旧配置默认参考速度为 0.10 m/s；若实测了新的停车距离，可将 `braking_distance_m` 和对应的 `braking_reference_mps` 一起更新。

原工程还有 `$S`（原地掉头）、`$P`、`$H`、`$O`，本自动避障桥不使用。尤其 `$S` 不是停车命令；`$D` 的速度传 0 会回退到默认 0.8 转/秒。因此停车必须明确写成 `$D0,0.050,0.00`。

## 上位机行为

- 默认 `drive_enabled:=false`：桥接只读 FireWater，不发送运动。
- `drive_enabled:=true` 只让桥接具备发令能力；仍需显式调用 `/vehicle/arm` 才发送 `$D`。
- 只有当 FireWater 新鲜、底盘状态为空闲/完成、视觉门禁为真、`/cmd_vel` 新鲜且非零时才发送一段。
- 实车直行按车身加两侧余量检查栅格。例如车宽 40 cm、每侧留 5 cm 时，检查与这 50 cm 通道有面积重叠的格子。弯道仍按转向时车身扫过的范围检查。水平相机的近地盲区由标定几何计算，只允许缺少地面观测，不能覆盖已检测到的障碍；直行前瞻末端仍需观测到地面。“前向检查距离”从车头量到通道内首个障碍或盲区以外首个未知格；它包含被跳过的盲区，不表示这段地面已被看到。
- 一段发出后，必须看到轮位置/调用次数变化或底盘进入运动状态，才认为命令被接收；超时则撤销使能并排队停车。
- 门禁关闭、`/cmd_vel` 为零、命令超时或服务撤销时，只排队一次 `$D0,0.050,0.00`。
- 反馈超时或串口读取失败会撤销使能，不自动恢复发令。

## 固有限制

原工程主循环只有 `Chassis_Done()` 时才取新指令，串口队列只能缓存后续动作；没有能中断当前动作的停车命令，也没有逐条应答。因此**上位机无法立即停车**。当前动作、可能的稳身/精修和减速必须结束后，排队的 `$D0` 才会生效。20 mm 短段和低速能缩短这个延迟，但不能消除。

这不满足要求即时停车的场景；现场仍需独立于上位机的电机断电或硬件急停。软件桥接不能替代它。

## 配置与启动

把 `config/vehicle.example.yaml` 复制到工程外并填写实测值。车身外廓已确认左右各 0.20 m（总宽 0.40 m），镜头横向居中、高 0.35 m、俯角 0°；前伸包括满舵扫掠，后伸取后轮半径 61.5 mm。相机坐标原点为后轴中心，向前/向左为正。当前已按前轮与后轮同径填写前悬 61.5 mm，镜头距后轴 0.335 m。仍需填入当前镜头 640×480 的内参和畸变文件、实测停车距离及独立断动力已实测状态。水平镜头设置 `zero_tilt_ack: true` 后，取图像底边视线与平地的交点作为盲区终点；按当前实车标定约为车头前 0.67 m。跨过该边界的栅格仍要求有地面观测。旧字段 `precleared_forward_m` 可作为更短的距离上限，不会扩大盲区。只读模式使用同样的标定。

只读检查：

```bash
source /opt/ros/humble/setup.bash
source .venv/bin/activate
source install/setup.bash
ros2 launch vision_avoid live.launch.py \
  profile:=indoor \
  serial_device:=/dev/serial/by-id/实际串口 \
  drive_enabled:=false
ros2 topic echo /vehicle/status
```

状态中的 `feedback_fresh` 必须为真，`board_state` 应能随手动推车或已有动作变化。若一直无反馈，先检查下位机是否运行上报版、PA9/PA10 是否交叉、共地、115200 和串口占用。

带动力启动：

```bash
ros2 launch vision_avoid live.launch.py \
  profile:=indoor \
  vehicle_file:="$HOME/vehicle.yaml" \
  serial_device:=/dev/serial/by-id/实际串口 \
  drive_enabled:=true \
  segment_m:=0.02
ros2 service call /vehicle/arm std_srvs/srv/SetBool "{data: true}"
```

先架空四轮、断开电机动力，确认请求使能后轮子不会自行转。再检查门禁关闭、撤销服务、杀掉桥接和拔串口时的行为。由于下位机没有急停命令，拔线测试只能验证上位机停止继续发令以及下位机完成当前动作后停车。
